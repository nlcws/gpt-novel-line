# STORY_PACK_CUTOUT_PROTOCOL v001

SP00 validates a writer-ready story pack cutout. The candidate must contain project-read evidence, root pack shape, episode folder shape, source address separation, layer binding, writer comfort check, and convergence evidence.

STOP instead of handing off when the candidate relies on summary, inferred source, unresolved layer/crosscheck residue, missing source addresses, or non-packager self-declaration.
