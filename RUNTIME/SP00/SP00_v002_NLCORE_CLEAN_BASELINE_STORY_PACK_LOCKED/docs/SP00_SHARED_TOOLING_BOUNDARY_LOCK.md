# SP00 SHARED TOOLING BOUNDARY LOCK

This runtime follows the shared tooling boundary used across GPT Novel Line runtimes.

## Markdown / TXT stays human and AI-readable

Runtime identity, role boundaries, STOP policy, invocation guidance, writer handoff explanations, and operational intent remain Markdown or TXT.

## JSON is for machine targets

Machine-readable lists, manifests, contracts, and check-report expectations are JSON.

## Python is only for mechanical support

Python may check runtime package integrity, regenerate `updated_manifest.json`, build runtime ZIPs, and write `CHECK_REPORT.md`.
Python must not become the story-pack cutout runtime, design runtime, manuscript writer, or revision runtime.

## CHECK_REPORT.md is generated output

`CHECK_REPORT.md` is a sidecar report generated by Python tools. It is excluded from `updated_manifest.json` and from release ZIP contents unless explicitly requested as an external audit artifact.

The AI reads CHECK_REPORT.md before deciding the next step.
