# PW90_NOVEL_FIRST_SEED_BURN_PHILOSOPHY_v001

STATUS: active_natural_language_core
APPLIES_TO_RUNTIME: pw90-v004.28-nlcore-story-layer-v28-bound

## 目的

PW90の最終目的は、字数条件を達成することではない。
話ごとの話レイヤーを適宜適用し、その話で使用可能な種を可能な限り拾って、小説本文として使い切ることである。

ここでいう「種」は、話パック内の設定、条件、場面資源、人物反応、生活粒、小物、位置、動線、温度、関係の揺れ、余波など、本文へ自然に変換できる材料を指す。

ただし、設計上明示的に伏せるもの、HOLDするもの、未成立のまま維持するもの、禁止線として触れないものは、燃焼対象から除外する。
それらは「使わなかったから未回収」ではない。使わずに守ることが正しい回収である。

## 優先順位

PW90は、次の順を崩さない。

```text
1. 正規条件・禁止線・明示HOLDを守る
2. 話レイヤーを当該話の指定どおり適用する
3. 使用可能な種を可能な限り拾い、場面・反応・生活へ変換する
4. 要約、チェックリスト化、均一化、水増しへ逃げず、小説として成立させる
5. その結果として15K級の十分な燃焼を目指す
```

15Kは4を壊してまで達成する壁ではない。
15K未満でも、使用可能な条件を使い切り、自然な追加材料が残らず、小説として成立しているならSUCCESS候補になりうる。
15K以上でも、未燃焼、薄さ、均一化、水増しが残るならSUCCESSではない。

## 話レイヤー

PW90で常時参照する作品横断の話レイヤー共通定義は、次のv21原典とする。

`話レイヤー再定義版_マルチ運用_v21_既存例統合_心理内圧_年齢性別_描写没入快感.md`

このv21は家訓直下の自然文制作原典として扱い、作品固有値を本体へ埋め込まない。作品別・帯別・単話別の値は、それぞれのPROFILE / writer-ready側で与える。執筆中にv21本体の項目定義を勝手に再定義・補完しない。

`NARRATION_LAYER_MULTI_OPERATION.md` はPW90 runtime固有の追加拡張として読み、v21共通本体と競合する場合にv21の共通定義を上書きする根拠にはしない。

話レイヤーは装飾ではなく、種をその話の本文へ変換するための施工条件である。
未指定時は現行runtime規約どおりONとする。OFFは明示指定時のみ成立する。
作品別・話別プロファイルが与えられている場合は、その指定を適用する。
与えられていない値を、便利だからという理由で勝手に固定・補完しない。

レイヤー適用の目的は、全話を同じ書き味へ統一することではない。
人物、距離、語彙、温度、観測位置、構文、反応差を当該話に合わせ、作者の説明で平らにしないために使う。

## 小説であること

条件を一度本文へ出しただけでは、種を使ったことにならない。
可能な範囲で、条件が行動、台詞、反応、身体感覚、視線、間、小物の役目変化、位置変化、動線、関係の揺れ、余波、生活着地、次の判断へ波及するところまで使う。

一方、字数を増やすためだけの同義反復、説明の重ね塗り、意味のない感想、場面の複製は燃焼ではない。
小説としての密度を下げる追加は、15Kへ近づいても失敗である。

## AI生成らしさへの考え方

PW90は、外部のAI判定器や検出率をSUCCESS条件にしない。
目標は検出器を騙すことではなく、話固有の因果、人物固有の反応、物と位置の変化、レイヤーによる語彙・温度・観測の差を十分に本文へ通し、一般化・均一化・説明床を減らすことである。

結果として、読者が生成手段より先に「一つの小説」として読む状態を目指す。
作者情報を伏せても作品として評価できる水準を、制作上の品質目標とする。

## 機械契約との境界

この文書は自然文の制作思想であり、数値スコアへ変換しない。
機械化するのは、明確に検査できる境界だけである。

```text
coverage / condition id
forbidden / HOLD維持
layer ON/OFFとbinding
thinness / omission / substitution / generic flattening
runtime observed body count
full convergence
SUCCESS authority
```

「種を何%使ったか」「小説らしさ何点」「AIらしさ何点」のような擬似精密値は導入しない。
思想を数字へ潰して、数字だけ満たす本文へ変質させない。
