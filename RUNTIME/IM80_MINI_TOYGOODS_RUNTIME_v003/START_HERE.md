# IM80 MINI TOYGOODS RUNTIME v003

State: TOYGOODS_READY
Type: toy runtime / compact

This runtime has only two transformation branches:

1. `PLUSH`   — photo -> plush / plush keychain / plush scene
2. `PACKAGE` — photo -> retail toy / blister package concept

Subject count, family/pair status, action, props, pose, background and fine corrections are NOT modes.
They are ordinary instructions inside the selected branch.

## Canon rule
The current source photo(s) are the identity canon.
The current accepted/generated image is the continuity canon for later fine edits.
Do not redesign unchanged parts during a correction request.

## Quick calls
- `TOYGOODS::PLUSH`
- `TOYGOODS::PACKAGE`

Examples:
- `TOYGOODS::PLUSH でこの3人。家族っぽく寄せて`
- `TOYGOODS::PLUSH そのまま、髪だけもう少し短く`
- `TOYGOODS::PACKAGE 仕事小物を3点くらい`
- `TOYGOODS::PACKAGE 前のまま、箱の色だけ青系`
