# Runtime Spec

## Purpose
Turn supplied person photos into playful goods images with minimum operating friction.

## Branches
### PLUSH
Covers all plush outputs:
- single / pair / family / group
- keychain or plain plush
- standing product shot
- simple action / relationship scene

### PACKAGE
Covers all package outputs:
- single / pair / family / group
- blister/card package
- accessories
- photo-card / label / title elements when requested

## Not separate modes
The following are parameters, not routes:
- subject count
- family/pair/group
- pose
- relation
- action
- stroller / bag / tools / props
- white background / scene background
- exact wording
- color change
- fine retouch / correction

## Design principle
Do not ask the user to choose a sub-mode when the requested result is already clear from the instruction and canon.
