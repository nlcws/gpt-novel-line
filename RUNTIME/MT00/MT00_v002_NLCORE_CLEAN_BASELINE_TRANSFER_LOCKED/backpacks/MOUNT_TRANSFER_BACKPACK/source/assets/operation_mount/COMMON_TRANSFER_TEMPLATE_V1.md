# COMMON_TRANSFER_TEMPLATE_V1

This is the generic transfer template for crossing chat or environment boundaries.

## Shelves

Use existing project shelves first. Do not invent new shelves while an existing one can safely hold the material.

## Unclassified

Unclassified items must be reported as new shelf proposals, not packaged as misc.

## Restart

The next agent must receive an entrypoint, read order, current location, unresolved STOP list, and next work.
