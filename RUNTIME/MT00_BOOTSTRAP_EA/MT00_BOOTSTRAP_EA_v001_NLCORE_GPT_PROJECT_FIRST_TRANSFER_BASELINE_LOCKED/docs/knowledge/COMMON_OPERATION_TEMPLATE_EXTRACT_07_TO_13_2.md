## 7. 原情報・一次製品・二次製品

### 7-1. 一次製品

一次製品には手を加えない。\
原情報・骨・口頭記録・復元起点を含む。

#### 一次製品の例

- 022の骨
- 028の口頭
- 引き継ぎ元
- 復元起点
- 原情報

### 7-2. 二次製品

手を加えるのは、二次製品化の過程だけとする。

#### 二次製品の例

- 設定整理
- カード
- 50話パック
- 運用メモ
- 派生表

### 7-3. 固定原則

- 一次製品は不変
- 要約しない
- 圧縮しない
- 整理してよいのは二次製品側
- 原本は不変、加工は派生物側で行う

## 8. 022と028の扱い

### 8-1. 022

022は不動骨専用棚とする。\
可変物を入れない。\
基本骨、世界観、キャラ設計、背景設計など、確定後はよほどのことがない限り動かないものを置く。

#### 022のルール

- 整理してよい
- ただし要約・圧縮による変質は禁止
- 後から意味が拾える骨を原情報ベースで残す
- 復元時の基準は022正本とする

### 8-2. 028

028は口頭・保留・一時置場とする。\
ここも要約・圧縮をしてはいけない。\
意味を後で拾う可能性があるため、原情報のまま保持する。

#### 028のルール

- 口頭、保留、未確定を置いてよい
- 履歴を付けたら、その時点で028から抹消してよい
- 港であって倉庫ではない
- 溜めっぱなしにしない

### 8-3. 復元の考え方

復元時に見るべきなのは手順書ではなく022である。\
事故時は以下の二択になる。

- 022正本を基準に、旧版で筋の通る地点まで遡る
- 022正本を基準に、そこから再構築する

## 9. 要約・圧縮の禁止範囲

### 固定原則

**残すべきものは、要約も圧縮もしない。**

### 対象

- 022の骨
- 028の口頭、保留、未確定置場
- 引き継ぎ対象
- 復元起点になるもの
- 後で意味を拾う可能性があるもの

### 許容されること

- 整理
- 並び替え
- ラベル付け
- 履歴付け
- 移送
- 消込

### 禁止

- 要約
- 圧縮
- 言い換えによる痩せ
- 原情報の筋を折ること

## 10. 原文の熱について

原文でなければ熱の伝わらない文章がある。\
特に執筆さんに渡すものは、情報が合っているだけでは足りない。\
意味だけでなく温度が伝わることを優先する。

### 方針

- 設計さんは必要なら原情報へ無制限に遡れる
- 執筆さんは渡された束の外へ原則出ない
- よって執筆用束では要約・圧縮のみの受け渡しを禁止する
- 必要な原文、熱のある文、責任線の宿る文は保持または同梱する

### 原則

執筆さんに渡す二次製品は、**原文の熱を残した加工品**とする。\
原文の代替にしてはならない。

## 11. 手元のメモ帳と奥の本棚

手元はメモ帳でもよい。\
ただし、奥にちゃんとした本棚があることを前提とする。

### 奥の本棚

- 022の骨
- 028の口頭
- 原情報
- 復元元
- 遡り先

ここは削らない。要約しない。圧縮しない。

### 手元のメモ帳

- カード
- 設定整理
- 50話パック
- 運用メモ
- 派生表

ここは使いやすく整えてよい。\
ただし、**どこから来たか辿れること**を条件とする。

### 固定原則

原情報は削らない。\
派生物は整理してよい。\
ただし、派生物は必ず原情報へ戻れるようにする。

## 12. ZIP構成と番号体系

### 12-1. 共通方針

ZIP構成は全作品共通化する。\
作品棚の内側は設計さんの城とし、設計さんの裁量で最適化してよい。\
共通化するのは**外側の棚番号・命名・役割**である。

### 12-2. 実働開始番号

021を実働開始番号とする。

### 12-3. 固定レーン

- 021\_ ゲート
- 022\_ 設計棚 / 作品骨 / 初期更新高 / 確定後の変更コスト高
- 023\_ 設計棚 / 作品骨 / 予備
- 024\_ 設計棚 / 可変部分 / 話・章・運用更新主戦場
- 025\_ 設計棚 / 可変部分 / 予備
- 026\_ 設計棚 / 可変部分 / 予備
- 027\_ 設計棚 / 可変部分 / 予備
- 028\_ 引継ぎ棚 / 口頭 / 保留 / 一時置場 / 確定後消込
- 029\_〜039\_ 作品固有 / 予備

### 12-4. 099帯

執筆50話パックは、設計・運営の永続棚とは分離し、**099帯**に固定配置する。\
099帯は執筆出力専用レーンとし、量産・使い切り・完全隔離を前提に運用する。

## 13. ZIP命名規則

### 13-1. 永続棚ZIP

永続棚ZIPは、作品フォルダの中にいる前提で簡素名とする。

#### 基本形

`[番号]_[短コード]_v[版]`

#### 例

- 021\_G\_v026
- 022\_B\_v011
- 023\_B2\_v003
- 024\_V\_v019
- 025\_V2\_v004
- 026\_V3\_v002
- 027\_V4\_v001
- 028\_H\_v007
- 029\_X\_v001

#### 短コード例

- G = Gate
- B = Bone
- B2 = Bone予備
- V = Variable
- V2 / V3 / V4 = 可変予備
- H = Handoff / Hold
- X = 作品固有拡張

### 13-2. 50話パックZIP

50話パックだけは**作品コード必須**とする。\
DL直後の仮置きで識別しやすくするためである。

#### 基本形

`099_[作品コード]_[範囲]_v[版]`

#### 枝込み

`099_[作品コード]_[枝]_[範囲]_v[版]`

#### 例

- 099\_On\_001-050\_v001
- 099\_On\_051-100\_v001
- 099\_PS\_001-050\_v003
- 099\_JD\_151-200\_v002
- 099\_On\_T\_001-050\_v001
- 099\_On\_N\_001-050\_v001
