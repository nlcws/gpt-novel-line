# 021 / 022 / 024 / 028 Bootstrap Shelf Rules

## 021_G_v000

Initial setup gate.
It provides the project-entry gate, reading order, shelf-sorting conditions, stop conditions, card standards, composition standards, and related setup references.

It is maximum-load input at construction time.
Unnecessary material may later be deleted, evacuated, or moved to reference shelves after design-side review.
It is not user project canon.

## 022_B_v000

Fixed bone shelf.

Allowed candidates:

- work core
- unchanging essence
- prohibitions
- world fixed bones
- character fixed bones
- terminology fixed bones
- items with high future change cost

This shelf must not lose heat or responsibility lines by summarization or compression.

## 024_V_v000

Variable and operational-update shelf.

Allowed candidates:

- chapter structure
- story cards
- existing plot
- after-text logs
- update notes
- pre-execution organization
- change candidates
- variable state

Thin cards must not be passed to writing.

## 028_H_v000

Oral condition / pending / temporary shelf.

Allowed candidates:

- oral conditions
- undecided items
- pending items
- temporary instructions
- cancelled items
- promotion candidates
- discard candidates

Chat, oral notes, and temporary instructions must not be promoted into work conditions without reason.
