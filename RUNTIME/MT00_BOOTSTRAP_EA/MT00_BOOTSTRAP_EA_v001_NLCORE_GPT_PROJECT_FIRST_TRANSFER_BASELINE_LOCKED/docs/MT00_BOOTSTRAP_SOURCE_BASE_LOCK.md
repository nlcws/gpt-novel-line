# MT00_BOOTSTRAP SOURCE BASE LOCK

## Required base shelves

MT00_BOOTSTRAP uses the four initial shelves as the base model.

| Shelf | Role |
|---|---|
| 021_G | Gate / initial setup gate |
| 022_B | Bone / fixed source shelf |
| 024_V | Variable / changeable work shelf |
| 028_H | Handoff-Hold / oral, pending, temporary shelf |

## Important source rules

- 021 is the first setup gate.
- 022 is fixed bone.
- 024 is the main variable work area.
- 028 is oral / pending / temporary.
- 099 must not be created as an initial shelf.
- 023, 025-027, 029-039 are reserves and are not created until needed.
- Project materials are not inserted until the design-side permission exists.
- Users must not be forced to unzip, inspect, or select internal files manually.

## Bootstrap handling

MT00_BOOTSTRAP may copy or preserve base shelves.
It may create initial derived shelf structure.
It must not treat sample material from 021 as project canon.
