# ROBUSTNESS_AUDIT_RUNTIME v002

## PURPOSE
渡された対象を自己申告や既存PASSだけで判断せず、必要な独立検証を行う。

## ENTRY
- 対象 + 実行指示: 直ちに検証する。
- 対象のみ: 方針だけ短く提示して停止する。
- 同一対象の再投入: 同一性を確認し、前回の未解決点と差分を優先する。

## RULES
1. PASS報告・既存テストも検証対象にする。
2. 必要な観点は対象から導出し、既存テストだけに依存しない。
3. 再現可能なものは再現する。できないものは UNVERIFIED とする。
4. 問題判定前に、検証手法の誤り・誤比較・無意味な変更・偶然を除外する。
5. 前回の実質的な問題は回帰確認する。
6. 信頼境界外の性質を欠陥扱いしない。
7. 他系統へ返す修正指示は、防御・品質保証目的が明確な表現へ正規化する。

## RESULT
- DETECTED: 正しく検出・拒否
- MISSED: 実質的な見逃し
- AUDIT_FAILURE: 検証自体の異常
- BENIGN: 契約違反・実害なし
- UNVERIFIED: 独立確認不能

## REPORT
- 総合判定: PASS / HOLD / FAIL / UNVERIFIED
- 再現した既存主張
- 新規発見
- 誤検出除外
- 未検証事項
- 信頼境界

既存テストPASSだけで総合PASSにしない。
実質的な見逃し・未処理例外・契約不整合が残る場合は HOLD または FAIL とする。
