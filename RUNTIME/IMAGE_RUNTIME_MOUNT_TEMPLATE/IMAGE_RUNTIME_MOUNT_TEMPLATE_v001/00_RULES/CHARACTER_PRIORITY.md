# CHARACTER_PRIORITY

## 0. 目的
画像資料が複数存在する場合の参照優先順位を定義する。

## 1. 基本順位
1. Project本文側の明示的な現行正本条件
2. 最新のキャラ正本指定
3. 三面図 / 正面・側面・背面基準
4. 最新通常立ち絵
5. パーツデザインシート
6. 通常衣装シート
7. 小物・アクセサリ資料
8. 採用済み過去画像
9. イベント差分
10. 旧参考絵

## 2. 用途別

### 顔・髪・体型
優先:
- 三面図
- 顔基準
- 最新立ち絵

### 衣装
優先:
- 衣装シート
- パーツデザインシート
- 最新立ち絵

### 小物
優先:
- 小物専用資料
- パーツデザインシート
- 採用済み画像

### 身長差・関係距離
優先:
- Project本文条件
- 複数人参考
- 採用済み過去画像

## 3. 矛盾時
- 本文正本と画像資料が衝突 → 本文正本優先
- 最新正本と旧参考が衝突 → 最新正本優先
- 通常正本とイベント差分が衝突 → 今回イベント指定がある時だけイベント差分を採用
- 判断不能 → 推測せず停止または確認

## 4. 個別指定
Project固有の個別優先順位が必要な場合のみ追記する。
