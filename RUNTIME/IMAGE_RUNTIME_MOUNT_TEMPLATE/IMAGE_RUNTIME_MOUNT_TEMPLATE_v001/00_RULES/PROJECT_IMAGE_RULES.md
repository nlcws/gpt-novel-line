## 5. イベント差分
- イベント差分は任意。
- 存在しない場合は通常基準資料だけで生成する。
- 存在する場合も通常正本を置き換えない。
- イベント専用衣装が明示されている場合のみ、その衣装を適用する。

---

## 6. 過去採用画像
- 継続性維持の参考にしてよい。
- 現行正本より上位には置かない。
- 過去画像の誤差を正本へ逆輸入しない。

---

Project固有ルールが本当に必要になった時だけ追記する。
