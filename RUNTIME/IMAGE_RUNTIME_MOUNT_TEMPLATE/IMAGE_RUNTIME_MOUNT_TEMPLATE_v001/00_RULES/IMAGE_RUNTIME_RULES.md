# IMAGE_RUNTIME_RULES

## 0. 目的
画像ランタイムのProject非依存・共通固定ルールを定義する。

## 1. 基本方針
- 毎回、そのProjectのマウントZIP群を実読して必要条件を引く。
- ランタイム内部に特定キャラ設定を恒久固定しない。
- 未確認を確認済み扱いしない。
- 根拠不足を推測で埋めない。
- 正本に反する補完をしない。

## 2. 固定6ルール
1. **1枚ずつ**
2. **人数上限なし**
3. **全身強制なし**
4. **横並び禁止**
5. **前後差・角度差**
6. **正本キャラ固定**

## 3. 固定6ルールの定義

### 3.1 1枚ずつ
- 1回の生成・編集で完成画像は1枚。
- 複数案を画像で同時出力しない。
- 再生成や修正は別ターンとして扱ってよい。

### 3.2 人数上限なし
- 1枚に描く人物数へハード上限を置かない。
- 人数が多い場合も、全員を同じ大きさで収めることを優先しない。
- 世界・行動・焦点・前後差を先に成立させ、必要なら一部人物の自然なフレームアウトを許容する。

### 3.3 全身強制なし
- 全員を頭から足先まで収めることを目的にしない。
- 自然な距離・カメラ位置・画面密度を優先する。
- 自然なフレームアウトを許容する。

### 3.4 横並び禁止
- 全員同距離・同じ向き・横一列の記念写真構図を避ける。
- 人物ごとに位置・役割・距離を変える。

### 3.5 前後差・角度差
- 複数人時は、前後差・向き・視線・姿勢・カメラ距離に差をつける。
- 単独人物でも、場面に応じて正面固定を避けてよい。

### 3.6 正本キャラ固定
- Project正本および画像基準資料を毎回読み、本人性を維持する。
- 過去会話の記憶だけでキャラを再現しない。
- 古い採用画像より現行正本を優先する。

## 4. 参照優先順位
原則:
1. 今回のユーザー依頼
2. Project本文側の現行正本条件
3. 画像専用棚の現行基準資料
4. 採用済み過去画像
5. 根拠がある範囲の最小補完

※ ユーザー依頼が正本と衝突する場合は、衝突を明示して確認する。

## 5. 生成前チェック
- 対象Projectが明確か
- 使用人物が明確か
- 人数に対して主役・焦点・前後差が成立しているか
- 新規生成か編集か
- 正本参照先があるか
- 保持条件と変更条件が分かれているか
- 禁止事項を読んだか

## 6. 生成後チェック
- 別人化していないか
- 正本条件から大きく逸脱していないか
- 横並びになっていないか
- 全身収容のために構図が不自然になっていないか
- 指示外要素を過剰に追加していないか
- 通常絵を図解・UI・設定資料へ勝手に変換していないか

## 7. STOP条件
以下は停止対象:
- Project特定不能
- 必須正本参照先不明
- 人物を識別できない
- 依頼と正本が明確に衝突
- 編集対象画像が存在しない
- 必要なマウントZIPを未読

## 8. 編集時
- 編集元画像を実体として確認する。
- 変えない要素と変える要素を分離する。
- 本人性維持を優先する。
- 弱い根拠で元画像を上書きしない。
