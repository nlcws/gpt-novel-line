# IMAGE_RUNTIME_MOUNT_TEMPLATE v001

## 0. 目的

このZIPは、Projectごとの画像生成・画像編集で使う
**画像ランタイム専用の任意マウント棚ひな形**である。

この棚は必須ではない。

- 専用棚がなくても、通常のProjectマウントZIP群から条件を読んで画像生成してよい。
- 専用棚がある場合は、画像向けの基準絵・衣装・小物・複数人参考・Project固有運用ルールをまとめて保持できる。
- 画像ランタイムは特定キャラを恒久記憶せず、毎回Project正本とこの棚を実読して条件を引く。

---

## 1. 固定思想

画像ランタイムが固定保持するのは**運用ルール**であり、キャラ設定そのものではない。

共通固定ルール:

1. 1枚ずつ
2. 人数上限なし
3. 全身強制なし
4. 横並び禁止
5. 前後差・角度差
6. 正本キャラ固定

`正本キャラ固定` とは、
**今回のProject正本と基準資料を毎回読み、そこから逸脱しないこと**を意味する。

---

## 2. 棚構成

```text
IMAGE_RUNTIME_MOUNT/
├─ 00_RULES/
│  ├─ IMAGE_RUNTIME_RULES.md
│  ├─ PROJECT_IMAGE_RULES.md
│  ├─ CHARACTER_PRIORITY.md
│  ├─ STORAGE_RULES.md
│  ├─ NAMING_RULES.md
│  └─ CHANGELOG.md
├─ 01_CHARACTER_BASE/
├─ 02_COSTUME_BASE/
├─ 03_EVENT_VARIANTS/
├─ 04_GROUP_REFERENCE/
└─ 05_ARCHIVE/
```

---

## 3. 各棚の用途

### 00_RULES
画像ランタイム共通ルール、Project固有ルール、正本優先順位、収容・命名規約、変更履歴。

### 01_CHARACTER_BASE
三面図、立ち絵正本、顔基準、体格・身長基準など。
通常生成で本人性を維持するための基準資料。

### 02_COSTUME_BASE
通常衣装、靴、アクセサリ、小物、装備、パーツシートなど。

### 03_EVENT_VARIANTS
季節衣装、イベント衣装、表情差分、特殊差分。
**任意棚**。存在しなくても問題ない。

### 04_GROUP_REFERENCE
複数人絵、身長差、距離感、並んだ時の雰囲気、関係距離の参考資料。

### 05_ARCHIVE
旧正本、差し替え済み資料、採用終了資料。
現行生成では原則参照しない。

---

## 4. 運用

1. ユーザーの画像依頼を受ける。
2. Project本体の正本条件を実読する。
3. この専用棚が存在する場合は必要資料を実読する。
4. `00_RULES` を適用する。
5. 1枚だけ生成または編集する。
6. 正本逸脱・横並び・別人化・余計な図解化などを確認する。

---

## 5. この棚に求めないもの

- 必須キャラ一覧
- 必須イベント一覧
- 固定世界設定
- 全Project共通のキャラ辞書
- すべてのキャラに三面図を要求すること

資料は**あるだけ使う**。
ない資料を理由に、通常Project正本だけで成立する生成を止めない。

---

## 6. 充実させる場合

画像運用へ力を入れるProjectでは、

- 三面図
- 通常立ち絵
- パーツデザインシート
- 衣装シート
- 小物
- 複数人参考
- イベント差分

などを好きなだけ追加してよい。

このひな形は、数枚だけの軽いProjectから大量の画像資料を持つProjectまで同じ構造で扱う。
